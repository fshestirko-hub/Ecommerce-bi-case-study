# Olist E-Commerce BI Case Study

## Objective

Business intelligence analysis of the Olist Brazilian e-commerce dataset. This project inspects operational data quality, evaluates logistical performance against customer churn, and provides some data-based, strategic recommendations for the platform.

## Data Architecture

The raw transactional data has been processed using Python and transformed into a Star Schema for DAX performance and SQL querying. 

* Fact Table: `Orders` (Filtered for realised revenue & orders volume, explicitly excluding freight costs).
* Dimension Tables: `Customers` and `Products` (flattened with English translations).

## Repository Structure

* `1_Data_Understanding.ipynb`: Python pipeline for data ingestion, cleaning, and SQLite serialisation.
* `2_Data_Analysis.ipynb`: SQL queries extracting core business metrics, data quality anomalies, and retention rates.
* `olist_ecommerce.db`: The compiled, analysis-ready SQLite database generated by Notebook 1.
* `Olist_Dashboard.pbix`: Power BI dashboard containing the final visualisations and DAX measures.

*Note: Raw CSV files are excluded from this repository. To reproduce the pipeline from scratch, download the dataset from Kaggle (https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce/data), place the CSVs in a /data folder, and execute Notebook 1.*
